# NutriFitness CT

Landing page institucional da academia NutriFitness CT.

## Visualização local

Abra o arquivo `index.html` no navegador ou execute um servidor estático na pasta do projeto.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `styles.css` — identidade visual e responsividade
- `script.js` — interações, menu e formulário

## Tecnologias

HTML, CSS e JavaScript sem dependências de build.
