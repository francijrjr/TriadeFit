# Portfólio — Francinilton Sobreira

Portfólio profissional de Francinilton Sobreira, programador e analista de sistemas.

## Executar

Abra `index.html` no navegador. O projeto é estático e não exige instalação.

## Configurar o WhatsApp

Em `script.js`, preencha `WHATSAPP_NUMBER` apenas com números, incluindo DDI e DDD:

```js
const WHATSAPP_NUMBER = "5588999999999";
```

O botão abrirá uma conversa com mensagem inicial pronta.
